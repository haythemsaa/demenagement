## 🛠️ INSTALLATION & DÉPLOIEMENT

### Prérequis :

```bash
- PHP 7.4+ ou 8.x
- MySQL 5.7+ ou MariaDB 10.3+
- Apache/Nginx avec mod_rewrite
- Composer (optionnel)
```

### Installation :

1. **Cloner le projet**
```bash
git clone [repository]
cd demenagement
```

2. **Configurer la BDD**
```bash
mysql -u root -p < database.sql
mysql -u root -p < database-multi-country.sql
```

3. **Configuration**
```php
// config/config.php
define('DB_HOST', 'localhost');
define('DB_NAME', 'demenagement');
define('DB_USER', 'root');
define('DB_PASS', '');
```

4. **Permissions**
```bash
chmod 755 -R .
chmod 644 config/*.php
```

5. **Accès**
- Site : `http://localhost/`
- Admin : `http://localhost/admin/`
- Email : `admin@demenageur.com`
- Pass : `admin123`
